# SQL LeetCode Solutions

Collection of solved SQL LeetCode problems.

## Overview

All SQL solutions are organized by problem ID in single files. Perfect for learning SQL and interview prep.

## Usage

1. Find the problem by ID (e.g., `175-Combine-Two-Tables.sql`)
2. Copy the SQL query
3. Run on LeetCode or your database

## Topics Covered

- JOINs (INNER, LEFT, RIGHT, FULL)
- GROUP BY & Aggregation
- Window Functions
- Subqueries & CTEs
- Date/String Functions
- Set Operations
- Data Modification
